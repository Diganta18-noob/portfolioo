# Diganta Biswas — Portfolio

A cinematic, responsive portfolio for Diganta Biswas. Built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run locally

```bash
npm run dev
```

Open <http://localhost:4173>.

## Edit

- Content and project links: `index.html`
- Layout and visual style: `src/styles.css`
- Menu, clock, and motion: `src/main.js`

The project visuals are stylized illustrations, not screenshots of the live products. Motion respects the system's reduced-motion preference. The site uses Google Fonts; local fallbacks remain available if fonts cannot load.

## Design references

The dark and lime direction is preserved. The hero's abstract orbital focal point draws on the visual approach of https://supahero.io/hero/abhishek-jha. The mobile menu's featured-work panel and large navigation links draw on Clonix in https://www.navbar.gallery/type/full-screen. All graphics and layout details are custom to this portfolio.

An unchanged copy of the original dark design is saved in `design-backups/original-dark/`.
